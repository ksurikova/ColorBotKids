ColorBotKids is an iPad application that turns a child's imagination into a coloring page — using only their voice.
A child speaks their idea ("draw a dragon riding a bicycle!"), the app transcribes and reads the prompt back aloud so the child can confirm it, then generates a custom AI illustration ready to color — right on screen.
For parents — one-time setup:
1. Configure your AI service (OpenAI or Stability AI API key)
2. Configure speech recognition & text-to-speech
3. Grant microphone and speech recognition access
4. Optionally grant Photos access to save finished artwork

For kids — pure magic:
1. Speak your idea out loud
2. Hear the app read back what it understood
3.  Tap to generate the coloring page
4. Start coloring!

Requirements
You'll need an API key from one of the supported AI providers:
* OpenAI (DALL·E)
* Stability AI
